# Frank Lite — one space for a few good notes

Frank Lite is a Mac writing app for a small, connected workspace. Write notes and explanations, include code, equations, tables, and images, and export a document when you want to share it.

Lite includes Frank's writing tools with a **hard limit of one space and three saved pages**.

**[Download Frank Lite 1.0.0](https://github.com/7drbw7mdgf-lgtm/frank/releases/download/lite-v1.0.0/Frank-Lite-1.0.0.dmg)** · [Installation guide](MACOS-INSTALL.md) · [See Frank's interface](../README.md)

## What fits in a Lite workspace?

You might keep a project brief, meeting notes, and a scratchpad together. Organize the pages, link related ideas, and use formatting or technical content wherever it helps the explanation.

A **page** means a saved note or document. It can contain more than one printed sheet; the limit is three saved documents, not three sheets of writing. Imports, duplicates, templates, daily notes, and new linked pages all count toward the same total.

Close or delete a saved page to make room, exporting its contents first if you need to keep them. Lite has separate workspace and settings storage from Full, so it can coexist with the Full app. Folder sync starts disabled; choose a separate folder if you enable it.

## Install

Requires **macOS 11 or later**, on Apple Silicon or Intel. Open the DMG and drag **Frank Lite.app** into Applications. This build is ad hoc signed and not Apple-notarized; follow the [first-launch guide](MACOS-INSTALL.md) if macOS blocks it. The DMG includes the matching `Allow-Frank-Lite.command` helper.

This folder contains the same installer, checksum, helper, and guide as the GitHub release. Need more spaces or pages? [Frank Full](../full/) has no built-in cap.
