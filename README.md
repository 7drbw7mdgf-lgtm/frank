| Edition | Download | Limits | Installation |
| --- | --- | --- | --- |
| Frank Full 5.5.1 | [DMG](https://github.com/7drbw7mdgf-lgtm/frank/releases/download/v5.5.1/Frank-5.5.1.dmg) | No space or page cap | [Guide](full/MACOS-INSTALL.md) |
| Frank Lite 1.0.0 | [DMG](https://github.com/7drbw7mdgf-lgtm/frank/releases/download/lite-v1.0.0/Frank-Lite-1.0.0.dmg) | 1 space, 3 saved pages | [Guide](lite/MACOS-INSTALL.md) |

Both apps require macOS 11 or later and run on Apple Silicon and Intel Macs. Drag the app from its disk image into Applications. These builds are ad hoc signed and not Apple-notarized; the guides describe approving each specific app locally.

Full and Lite restore the saved active page at startup and preserve current edits when creating or duplicating documents. Both editions include native DOCX opening, confirmation and rename dialogs, corrected folder sync, local HTML publishing, and interactive screen capture. Lite has separate workspace storage. Every normal page creation route enforces its cap, including imports, templates, daily notes and linked pages. Printed pagination inside a saved document is not the Lite page count.

Download folders: [Full](full/) · [Lite](lite/). Each contains the same DMG, checksum, installation guide and app-specific helper published with its release. The old Frank 2 download is retained for compatibility.

This repository distributes installers and support files. Editable application source and build/test files are kept locally, outside this public repository. GitHub always supplies automatic **Source code (zip/tar.gz)** links for the repository snapshot; those labels cannot be hidden. They are not a separately published application source tree. The shipped app still contains inspectable resources required to run it.
